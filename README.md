# Seventeen Syllables of Debugging

One haiku about debugging — three lines in the 5-7-5 syllable shape,
written to be read in one breath. The centre is concrete: a cursor
blinking at three in the morning, a stack trace ending in silence.
The last line turns the whole night into a single keystroke.

> Cursor blinks at three
> the stack trace ends in silence
> a missing comma

## Run

```sh
python3 main.py
```

Writes the haiku to `<MAKEFUN_OUTPUT_DIR>/entry.txt` (default
`/output/entry.txt`). Standard library only, deterministic, no network.
